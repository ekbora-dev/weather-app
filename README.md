# Weather App in ReactJS

Hello everyone ! This is my project of a weather developed with ReactJS framework ! You can give me feedbacks with issues for improvement tips !

## Installation
1. Download & install [Git](https://git-scm.com/install/) and clone this repository with :
```bash
git clone https://github.com/ekbora-dev/weather-app.git
```
2. Download & install [NodeJS](https://nodejs.org/en)
3. Go to the cloned project folder and execute (on the terminal):
```bash
npm install # or npm i
```

## Set up your API key

To make this web application work, you must have an API key from openweathermap.org

1. Go to https://openweathermap.org
2. Create an account (choose the free plan)
3. After creating your account, on the top right corner, click to your username and click on "my API key"
4. On this new page, set a name for your new API key and click "generate"

### Add this API to the web application

Go to the .env file and replace "Your API key goes here" by the generated API key from Open Weather Map

## Run the application
After all these steps, you can run the command below:
```bash
npm run dev
```
This command gives you the link where the website is hosted on your computer, you can open it on your favourite browser
